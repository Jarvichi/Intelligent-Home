# Intelligent Home - Discord - AI Bot

Discord AI bot: answers messages from allow-listed users on chosen channel keys (bus module of ih_discord) by asking the AI layer API and posting the reply.

- **Family:** Discord. Module of the `ih_discord` transport.
- **Needs:** `ih_discord`, `ih_ai_layer`, mqtt
- **Starts safe:** shadow mode, answers and posts nothing until you switch it on
