ABOUT THIS ADD-ON

Durable inbox for messages on chosen Discord channel keys, as a module of the ih_discord transport. It claims the channel keys you list, stores each message in a queue (7 days), reacts with an eye emoji so the sender knows it arrived, and never answers in the channel. Claude and workers read the queue over a token-protected local API. SHADOW mode by default: queue is written, no reactions. No Home Assistant access. Maps no folders.

This page reports service availability only. Configure options and secrets in the Home Assistant add-on settings.
