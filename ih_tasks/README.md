# Intelligent Home - Tasks

One list of tasks with clear stages, one approval step, and a full history per task.

- **Family:** Tasks (stands alone).
- **Needs:** nothing else. Home Assistant API access is used only if you turn on the to-do list mirror.
- **Starts safe:** it only keeps its own database. The mirror to a to-do list is off by default.
- Set-up, options, the API and the migration tool: [DOCS.md](DOCS.md)
- Version history: [CHANGELOG.md](CHANGELOG.md)
