# Intelligent Home - Usage Trace

Shows what used your Claude allowance: a chart of session and week usage with labelled events on top.

- **Family:** Orchestration (stands alone).
- **Needs:** the Claude usage sensors in Home Assistant (entity ids are options).
- **Starts safe:** shadow mode. It records the usage series; events are only logged until you set `mode` to `live`.
