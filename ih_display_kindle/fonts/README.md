# Kindle display fonts

These files are the unmodified Google Fonts distributions. Creepster, Bangers and
Monoton are distributed under the SIL Open Font License; Mountains of Christmas
is distributed under the Apache License 2.0. The corresponding licence texts
are included alongside them. Sources: https://github.com/google/fonts/tree/main/ofl/creepster,
https://github.com/google/fonts/tree/main/ofl/bangers,
https://github.com/google/fonts/tree/main/ofl/monoton and
https://github.com/google/fonts/tree/main/apache/mountainsofchristmas.

The original dashboard also used household-owned personal-use typefaces; those
are not included in this repository. Open-licensed substitutes are used instead.
