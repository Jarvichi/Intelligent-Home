# Kindle Display

Set `source_url` to the current Kindle picture URL and open the Kindle Display page. Refresh checks the image again; if the source becomes unavailable, the page labels the last received picture as stale. The source must be an HTTP(S) PNG or JPEG image without URL credentials. Keep the source on a trusted network.

This is a read-only preview of the existing generator. A replacement Kindle renderer, touch-zone map, cached screens and device cutover are not included. The Kindle keeps using its current source.
