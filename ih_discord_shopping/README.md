# Intelligent Home - Discord - Shopping

Shopping list commands for Discord as a bus module of ih_discord (add items, shop checklist by aisle with tick reactions, got ...).

- **Family:** Discord. Module of the `ih_discord` transport.
- **Needs:** `ih_discord`, mqtt
- **Starts safe:** shadow mode, answers and posts nothing until you switch it on
