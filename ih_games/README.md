# Intelligent Home Games

Turns game activity (PlayStation trophies, Xbox gamerscore, Steam, Destiny 2) into friendly chat: decides what is worth saying and queues messages for the chat bots.

- **Family:** Games. Stand-alone family member.
- **Needs:** `ih_discord`, mqtt
- **Starts safe:** dry-run, changes nothing until you switch it on
