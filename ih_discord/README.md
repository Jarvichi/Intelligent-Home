# Intelligent Home - Discord

Discord transport: one bot token, one poller per channel, signed MQTT bus for feature modules (ih_discord_house, ih_discord_shopping).

- **Family:** Discord. Parent of its family.
- **Needs:** mqtt
- **Starts safe:** dry-run, changes nothing until you switch it on
