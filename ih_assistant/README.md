# Intelligent Home - Assistant - Personas

Personal assistant transport for several personas in one add-on: reads each person's private Discord messages through that persona's own bot, queues check-ins and sends replies written elsewhere.

- **Family:** Assistant. Stand-alone family member.
- **Needs:** nothing else
- **Starts safe:** dry-run, changes nothing until you switch it on
