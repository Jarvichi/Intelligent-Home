# Intelligent Home - Discord - Task channels

Task channels for Discord as a bus module of ih_discord (one private channel per task, Work in Progress and Done categories, goal as topic, daily cleanup of old done channels).

- **Family:** Discord. Module of the `ih_discord` transport.
- **Needs:** `ih_discord`, mqtt
- **Starts safe:** shadow mode, answers and posts nothing until you switch it on
