ABOUT THIS ADD-ON

One private Discord channel per task, as a module of the ih_discord transport: commands new / done / reopen / list in a commands channel, goal as channel topic, Work in Progress and Done categories, daily cleanup of old done channels. It asks the transport (signed MQTT bus) to administer channels and never holds a Discord token. SHADOW mode by default: it creates nothing. No Home Assistant access. Maps no folders.

This page reports service availability only. Configure options and secrets in the Home Assistant add-on settings.
