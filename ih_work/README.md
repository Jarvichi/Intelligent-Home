# Intelligent Home - Work

The work queue for Claude: one line of jobs (first in, first out), a pace gate with day and night levels, a token-protected local API and a task view.

- **Family:** Work (stands alone).
- **Needs:** Home Assistant API access, only to read the Claude usage sensors and (if you turn it on) the Claude to-do list.
- **Starts safe:** test mode. It keeps the line but hands out nothing.
